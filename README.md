# 👁️ Smart Vision Surveillance System

Prototype web interface for a **smart vision surveillance system**, focused on monitoring and visual-event interaction.

## 📂 Cấu trúc

```text
smart_vision_surveillance_system/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🧩 Thành phần

- `index.html`: giao diện ứng dụng
- `style.css`: kiểu dáng giao diện
- `script.js`: logic tương tác phía client

## ▶️ Chạy

Mở `index.html` bằng trình duyệt hoặc dùng static web server.

> Chỉ cập nhật README; mã nguồn hiện có được giữ nguyên để tránh ảnh hưởng chức năng.
