# smart_vision_surveillance_system
Smart Vision Surveillance System là hệ thống giám sát thị giác thông minh ứng dụng OpenCV, YOLO và Face Recognition. Dự án tích hợp các tính năng streaming, phát hiện chuyển động, đếm người, nhận diện biển số, khuôn mặt (Face ID) và mã QR, quản lý qua Flask và SQLite/PostgreSQL.
