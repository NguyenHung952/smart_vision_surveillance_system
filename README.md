# 📖 Giới thiệu

**Smart Vision Surveillance System** là hệ thống giám sát thông minh tích hợp Computer Vision, AI Detection và Camera Realtime phục vụ học tập, nghiên cứu và phát triển các ứng dụng Smart Campus / Smart City.

Project tập trung vào:

- 🎥 Camera realtime streaming
- 🚶 Phát hiện chuyển động
- 👥 Đếm người bằng AI
- 🚗 Nhận diện biển số xe
- 🅿 Smart parking simulation
- 😀 Face Recognition
- 🔓 Mở cửa bằng Face ID
- 📱 QR Code Attendance System

Hệ thống phù hợp cho:

- AI Camera Systems
- Computer Vision Research
- Smart Campus
- Smart Parking
- Surveillance Systems
- Edge AI Applications
